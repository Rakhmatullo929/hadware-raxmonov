# Печать/PDF аренды в виде таблицы позиций

**Дата:** 2026-08-04
**Статус:** утверждён

## Цель
Кнопки «Печать договора» и «Скачать PDF» на странице аренды выдают плоскую
таблицу позиций (образец — фото клиента), а не текст договора. Формальный
договор (стороны, условия, узбекские заголовки) убирается.

## Колонки (сгруппированный заголовок)

```
Код клиента | Товар{Наименование|Кол-во|Стоимость|Общая сумма} | Дата{Отправки|Привозки} | Время{Отправки|Привозки}
```

Клиент (ФИО/телефон) — в строке-подписи над таблицей, НЕ колонкой.

| Колонка         | Источник |
|-----------------|----------|
| Код клиента     | `rental.customer.code` (повторяется в каждой строке) |
| Наименование    | `it.product.name` |
| Кол-во          | `it.qty` |
| Стоимость       | `it.price_per_day` |
| **Общая сумма** | `billing.compute_item_base(it)` — кол-во × цена × дни (FIFO, мин. 1 день, с учётом ручных правок при возврате) |
| Отправки (дата/время) | **первое** движение `Movement` kind=ISSUE этой позиции |
| Привозки (дата/время) | **последнее** движение kind=RETURN; если не возвращено — «—» |
| Итого (tfoot)   | Σ `qty`, Σ `compute_item_base` |

## Поведение
- Числа берутся из биллинга системы → могут слегка отличаться от старого
  бумажного образца (напр. 4×28×6000=672 000 против 665 000 на фото). Это
  согласовано с карточкой «База» на странице аренды.
- Ориентация: **альбом** для всех трёх форматов (A4/A5/A6). Кнопки форматов
  не меняются, отличие — бумага/размер шрифта.
- Водяной знак «Raxmonov» и панель печати сохраняются.

## Затрагиваемые файлы (без изменений БД/миграций)
- `config/views.py::rental_contract` — считает `it.item_total`, `it.issue_dt`,
  `it.return_dt`, `total_qty`, `grand_total`; prefetch `items__movements`.
- `config/templates/config/rentals/contract.html` — новая таблица + подпись,
  убрать разделы договора, заголовки на русском, альбом для всех размеров.
- `config/contract_pdf.py` — `_draw_items_table` под новые колонки (двухрядная
  «шапка»), `build_contract_pdf` без разделов сторон/условий, orientation='L'
  для всех layout, подпись клиента, русский заголовок.
