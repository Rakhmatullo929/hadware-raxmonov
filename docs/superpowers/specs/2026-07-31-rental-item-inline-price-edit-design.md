# Инлайн-редактирование «Цена/сут.» в таблице позиций

**Дата:** 2026-07-31
**Статус:** одобрено, в реализации

## Цель
Дать возможность менять цену за сутки у позиции аренды **прямо в ячейке**
«Цена/сут.», не открывая модалку по кнопке-карандашу справа. Кнопка-карандаш
остаётся — она по-прежнему нужна для правки количества.

Доступно только админу (как и текущая правка позиции). У оператора ячейка
остаётся обычным текстом без возможности клика.

## Взаимодействие
1. Клик по ячейке цены (админ) → её содержимое заменяется на инлайн-форму:
   `[поле ввода] [✓] [✗]`. Поле сразу в фокусе, показывает текущую цену без
   локали (`2000.00`, через `|unlocalize`), выравнивание по правому краю.
2. **✓** (submit) или **Enter** → HTMX POST сохраняет цену → **OOB-перезагрузка
   карточки аренды**, чтобы пересчитались зависимые колонки **Σ/сут.
   (цена × кол-во)** и **Сумма возврата**. Тот же приём, что уже у модалки
   (`_oob_response(_reload_rental(...))`).
3. **✗** → HTMX GET возвращает обычное отображение ячейки, без сохранения.
4. Неверная цена (не число / отрицательная) → сервер возвращает инлайн-форму с
   красной рамкой поля и коротким сообщением-подсказкой; цена не меняется.

## Подход
Класс-вью + HTMX «click-to-edit», как принято в проекте. Разбор цены общий с
модалкой — выносим в хелпер (DRY), чтобы правила совпадали в обоих местах.

## Компоненты
- **`config/views.py`:**
  - Хелпер `_parse_price_per_day(raw) -> (Decimal | None, error | None)` —
    вынести из `RentalItemEditView.post` (строки 2313–2327): нормализация
    (пробелы, `\xa0`, запятая→точка), `Decimal`, проверка `>= 0`,
    `quantize('0.01')`. Использовать в модалке и в инлайне.
  - Новый **`RentalItemPriceEditView(AdminRequiredMixin, View)`**:
    - `GET` → рендер `_price_cell_edit.html` (поле + ✓ + ✗) в ячейку.
    - `POST` → `_parse_price_per_day`; при ошибке → тот же `_price_cell_edit.html`
      с `error` и введённым значением; при успехе →
      `item.save(update_fields=['price_per_day'])` + `messages.success` +
      `_oob_response(request, _reload_rental(rental.pk))`.
  - Новый **`RentalItemPriceCellView(AdminRequiredMixin, View)`** (или `GET`-ветка
    отдельным именем): рендер `_price_cell.html` — обычная ячейка. Нужен для
    кнопки отмены (✗), чтобы вернуть отображение без сохранения.
- **`config/urls.py`:** два маршрута —
  `rental_item_price_edit` (GET/POST) и `rental_item_price_cell` (GET),
  оба с `pk` (аренда) и `item_pk` (позиция), рядом с `rental_item_edit`.
- **Шаблоны:**
  - `config/templates/config/rentals/_price_cell.html` — отображение: для админа
    кликабельный span (`hx-get` на `rental_item_price_edit`,
    `hx-target` = сама ячейка, `hx-swap="innerHTML"`, `role="button"`,
    `title="Изменить цену"`); для не-админа просто `{{ item.price_per_day }}`.
  - `config/templates/config/rentals/_price_cell_edit.html` — форма: `input`
    `type=number min=0 step=0.01` c `autofocus`, кнопка ✓ (`hx-post`
    `rental_item_price_edit`, `hx-include` поля), кнопка ✗ (`hx-get`
    `rental_item_price_cell`). Обе `hx-target` = ячейка, `hx-swap="innerHTML"`.
    При `error` — класс `is-invalid` на поле + текст ошибки.
  - **`_items_table.html`:** ячейку цены (строка 52) заменить на
    `<td class="text-end" id="price-cell-{{ it.pk }}">{% include 'config/rentals/_price_cell.html' with item=it rental=rental %}</td>`.
    `hx-target` у элементов внутри — `#price-cell-{{ it.pk }}`.

## Крайние случаи
- **Не-админ** → у ячейки нет клика/hx-атрибутов; прямой запрос к вью
  `rental_item_price_edit`/`_cell` → 403 (`AdminRequiredMixin`).
- **Неверный ввод** (пусто, текст, минус) → инлайн-форма с ошибкой, цена как
  была.
- **Пересчёт зависимых колонок** — за счёт полной OOB-перезагрузки карточки
  (Σ/сут., Сумма возврата, Итог). Отдельной логики не нужно.
- **Закрытая аренда** — правка цены разрешена админу так же, как в модалке
  (её поведение не меняем).
- **Аудит** — сохранение идёт через `item.save(...)`, значит изменение цены
  автоматически попадает в журнал действий (post_save). Бонус, отдельного кода
  не требует.
- **Кнопка-карандаш** — не трогаем; правка количества по-прежнему через модалку.

## Тесты
`tests/test_rental_item_price_edit.py` (рядом с существующими тестами правки
цены):
- `GET rental_item_price_edit` (админ) → 200, в ответе `input` с текущей ценой
  (`|unlocalize`), кнопки ✓/✗.
- `POST` валидной цены (админ) → цена обновлена в БД; ответ — OOB-карточка;
  новая Σ/сут. (цена × кол-во) присутствует в HTML.
- `POST` мусора/отрицательной → 200 с формой-ошибкой (`is-invalid`), цена в БД
  не изменилась.
- `GET rental_item_price_cell` (отмена) → 200, обычная ячейка, без записи.
- Не-админ (staff): `GET`/`POST` → 403.
- Не-админ видит цену как текст, без кликабельного span (проверка в рендере
  таблицы карточки).
- Модалка правки позиции по-прежнему работает (общий хелпер `_parse_price_per_day`
  не сломал её): существующие тесты зелёные.
- Полный `pytest` зелёный.

## Заметки
- Enter в поле отправляет форму (штатное поведение), поэтому Enter = ✓
  бесплатно. Esc-отмену не добавляем (есть кнопка ✗) — можно позже.
- Формат ввода — без разделителей (`2000.00`); вывод в ячейке — как у соседних
  денежных колонок (ru-локаль, `2000,00`).
